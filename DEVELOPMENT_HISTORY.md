# Vampire Roguelite — История разработки

## Проект
- **Файл игры**: `roguelite.html` + `roguelite.js` + `roguelite.css`
- **Движок**: Phaser 3.60.0
- **Стек**: HTML/CSS/JS, Phaser 3, без сборщиков — открывать через локальный HTTP-сервер
- **Запуск**: `http://localhost:8080/roguelite.html`

---

## Что было сделано (хронология)

### 1. Базовая игра
- Roguelite-шутер (вдохновение: Vampire Survivors)
- Арена без краёв, случайный спавн врагов
- Система прогресса: опыт → уровень → выбор улучшений

### 2. Визуал
- Убраны emoji-иконки, заменены на canvas-рисованные иконки оружий
- Фон — процедурно генерируемый тёмный пол с текстурой плитки
- Персонаж и враги рисуются через Phaser Graphics API

### 3. Аудио
- Фоновая напряжённая музыка (синтез через Web Audio API в `audio.js`)
- Реалистичные звуки оружий: огонь, лёд, молния, взрыв
- Настройки звука в меню паузы (ESC)

### 4. Управление
- Клавиатура: WASD / стрелки
- Мобильный сенсорный джойстик — появляется при касании в любом месте экрана
- Полная адаптация под любой размер экрана

### 5. Система оружий (16 видов)
1. Огненный шар — летит в ближайшего врага, взрывается
2. Ледяная стрела — замедляет, пробивает насквозь
3. Цепная молния — прыгает между врагами
4. Топоры-бумеранги — спираль с кулдауном, возвращаются к игроку
5. Магические мины — раскладываются по полу, взрываются при наступлении
6. Молот правосудия — падает с неба, создаёт ударную волну
7. Кольцо льда (Frost Nova) — взрыв вокруг игрока, замораживает
8. Метеоритный дождь — метеориты в зону вокруг игрока
9. Тесла-сфера — шар орбитирует вокруг игрока, бьёт молниями
10. Теневой клинок — быстрые удары по ближайшим врагам
11. Кровавая аура — постоянный урон в радиусе + лечение игрока
12. Хаотичный вихрь — снаряды вращаются вокруг игрока
13. Призрачный луч — медленный лазерный луч, вращается
14. Ядовитое облако — оставляет лужи яда на поле
15. Огненная дорожка — огонь там, где ходил игрок
16. Небесный гром — молния бьёт по случайным врагам на экране

### 6. Система реликвий (16 видов)
Пассивные улучшения: скорость, HP, реген, урон, кулдаун и т.д.
Золотой Крест — +25 макс. HP и лечение (это ОРУЖИЕ, имеет уровни)

### 7. Синергии (суперэволюции)
При определённых комбинациях предметов на макс. уровне открывается эволюция

### 8. UI/UX
- **Статусбар**: HP вверху (с числами внутри), ячейки оружий и реликвий под ним
- **Меню паузы** (ESC): настройки звука, гримуар, выход
- **Гримуар**: только в главном меню
- **Карточки улучшений**: тег ОРУЖИЕ/РЕЛИКВИЯ/СУПЕРСИНЕРГИЯ, редкость, имя, описание
- **Клавиатурная навигация**: 1/2/3 или ←→ + Enter

### 9. Исправленные баги
- **Краш при взрыве мины и молоте правосудия**: Phaser 3.60 убрал `tween.getValue()` и `tween.getProgress()`. Все 5 мест с `tweens.addCounter` заменены на объектные твины (`add.circle` + `tweens.add`)
- **Тесла-сфера**: молнии исходили из игрока вместо шара — исправлено
- **Топоры**: спираль + плавное исчезновение с правильным кулдауном
- **Статус звука в меню**: текст синхронизируется с состоянием
- **Гримуар пустел**: исправлена инициализация
- **Карточка без типа (Золотой Крест)**: добавлены теги типа ко всем картам

## Как запустить на новом ПК
1. Распаковать архив `roguelite_project_backup_*.zip`
2. Открыть папку в VS Code
3. Запустить локальный сервер:
   ```bash
   cd "Test alternate games"
   npx http-server -p 8080
   ```
   Или использовать расширение **Live Server** в VS Code
4. Открыть: `http://localhost:8080/roguelite.html`
